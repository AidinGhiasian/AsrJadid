# دانلود قالب‌های سایت عصرجدید

این شاخه فقط برای دانلود دو بستهٔ ZIP ساخته شده است و **هیچ ارتباطی با کد پروژه ندارد**.
پس از دانلود می‌توانید کل این شاخه را حذف کنید (Settings → Branches یا با یک دستور git push --delete).

| فایل | توضیح |
|---|---|
| `theme1-classic.zip` | قالب ۱ — کلاسیک لوکس (کرم/طلایی)، ۴۱ صفحه سایت + ۱۱ صفحه پنل مدیریت |
| `theme2-modern.zip`  | قالب ۲ — مدرن شهری (سفید/سبزآبی)، ۴۱ صفحه سایت + ۱۱ صفحه پنل مدیریت |

ورود نمایشی پنل مدیریت: `admin / admin123`

هر بسته کاملاً مستقل است: صفحات HTML در ریشه، پوشهٔ `admin/`، و `assets/{css,js,images,fonts}` — بدون هیچ وابستگی به اینترنت.
