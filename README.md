# عصرجدید — سنگ مصنوعی | Asr-Jadid 1.0.0

فروشگاه اینترنتی «سنگ مصنوعی عصرجدید»؛ پروژهٔ کامل **ASP.NET Core 9 (Razor Pages)** با **قالب «مدرن شهری»** که به‌عنوان فرانت‌اند سایت روی پروژه سوار شده است (سایت + پنل مدیریت + اتصال به پایگاه داده).

## ساختار مخزن

```
├── AsrJadid/                    برنامهٔ وب (میزبان + صفحات Razor + فایل‌های استاتیک)
│   ├── Pages/                   صفحات سایت و پنل مدیریت — همان قالب «مدرن شهری»
│   ├── wwwroot/assets/          css / js / images / fonts قالب (بدون وابستگی خارجی)
│   └── Data/SeedData.cs         داده‌های اولیه (نقش‌ها، مدیر، دسته‌ها و محصولات نمونه)
├── AccountManagment*/           ماژول حساب کاربری (Domain / Application / Infrastructure)
├── StoneManagement*/            ماژول سنگ و دسته‌بندی (Domain / Application / Infrastructure)
├── Services/                    سرویس‌های مشترک (احراز هویت، هش رمز، آپلود فایل، ابزارها)
└── websites/
    ├── 2-asrjadid-modern/       قالب HTML مستقل «مدرن شهری» (قابل باز شدن در مرورگر)
    ├── _src/                    مولد قالب (Python) — برای بازسازی قالب از صفر
    ├── make-zips.sh             ساخت بسته‌های ZIP تحویلی
    └── download/                صفحهٔ دانلود + بسته‌های تحویلی
```

## فرانت‌اند

فرانت‌اند این نسخه، **قالب «مدرن شهری»** است که به‌شکل کامل به Razor Pages تبدیل و به پروژه چسبانده شده است:

- **صفحات سایت**: `AsrJadid/Pages` — خانه، محصولات، دسته‌ها، لیست قیمت، گالری، سبد خرید، تسویه، حساب کاربری، وبلاگ، تماس، و…
- **پنل مدیریت**: `AsrJadid/Pages/Admin` — داشبورد، محصولات، دسته‌ها، مشتریان، نقش‌ها، سفارش‌ها، تنظیمات
- **دارایی‌ها**: `AsrJadid/wwwroot/assets` (css/js/images/fonts)
- **نسخهٔ مستقل HTML قالب** (بدون نیاز به .NET، فقط با دابل‌کلیک `index.html`): `websites/2-asrjadid-modern`

## اجرا

پیش‌نیاز: [.NET SDK 9](https://dotnet.microsoft.com/) و دسترسی به SQL Server.

```bash
dotnet restore
dotnet run --project AsrJadid
```

- پایگاه داده در اولین اجرا به‌صورت خودکار ساخته و مقداردهی اولیه می‌شود (`AsrJadidDB` روی `Server=.`).
- نشانی سایت: `https://localhost:5001` (یا پورت نمایش‌داده‌شده در خروجی).
- **ورود مدیر**: `09159861216` / `admin123` — نشانی پنل: `/Admin/Login`

## بسته‌های تحویلی (ZIP)

با اجرای `websites/make-zips.sh` دو بسته در `websites/download/` ساخته می‌شود:

| بسته | محتوا |
| --- | --- |
| `Asr-Jadid-1.0.0.zip` | پروژهٔ کامل به‌همراه فرانت‌اند (قالب «مدرن شهری» چسبیده به پروژه) + نسخهٔ مستقل HTML قالب |
| `Asr-Jadid-template.zip` | فقط قالب «مدرن شهری» به‌صورت HTML مستقل (۳۴ صفحه + ۱۱ صفحه پنل) |
