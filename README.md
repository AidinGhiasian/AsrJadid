# دانلود قالب سایت عصرجدید

این شاخه فقط برای دانلود بستهٔ ZIP ساخته شده است و **هیچ ارتباطی با کد پروژه ندارد**.
پس از دانلود می‌توانید کل این شاخه را حذف کنید.

| فایل | توضیح |
|---|---|
| `theme2-modern.zip` | قالب «مدرن شهری» (سفید/سبزآبی)، ۴۱ صفحه سایت + ۱۱ صفحه پنل مدیریت |

ورود نمایشی پنل مدیریت: `admin / admin123`

بسته کاملاً مستقل است: صفحات HTML در ریشه، پوشهٔ `admin/`، و `assets/{css,js,images,fonts}` — بدون هیچ وابستگی به اینترنت.
