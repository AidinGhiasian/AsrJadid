# قالب سایت فروشگاهی سنگ مصنوعی عصرجدید — پوسته ۱ — کلاسیک لوکس

قالب کامل راست‌چین (RTL) همراه با **پنل مدیریت**، آماده برای تبدیل به Razor Pages در پروژه ASP.NET Core.

## ساختار پوشه‌ها

```

├── about.html              درباره ما
├── categories.html         دسته‌بندی محصولات
├── products.html           لیست محصولات (فیلتر قیمت/دسته/رنگ + گرید و لیست)
├── product.html            جزئیات محصول (گالری، تب‌ها، مشخصات، دیدگاه)
├── category.html           آرشیو یک دسته‌بندی
├── services.html           خدمات
├── service.html            جزئیات خدمت + محاسبه‌گر متراژ و هزینه
├── projects.html           پروژه‌های اجرایی
├── project.html            جزئیات پروژه

├── blog.html               وبلاگ
```

## ورود نمایشی

| بخش | نام کاربری | رمز |
|---|---|---|
| پنل مدیریت | `admin` | `admin123` |
| حساب مشتری | `۰۹۱۲۱۱۱۲۲۳۳` | `demo1234` |

> داده‌ها نمونه و سمت کلاینت هستند؛ سبد خرید و علاقه‌مندی‌ها در `localStorage` ذخیره می‌شوند.

## ویژگی‌های فنی

- تمام صفحات HTML خالص + CSS و JS بدون وابستگی خارجی (بدون jQuery/Bootstrap) → سبک و سازگار با Razor Pages.
- فونت وزیرمتن به‌صورت محلی در `assets/fonts` (بدون نیاز به CDN خارجی).
- کاملاً واکنش‌گرا (موبایل، تبلت، دسکتاپ) و راست‌چین.
- سئو: تگ‌های متا، ساختار عنوان‌ها، نام‌گذاری معنایی و مسیرهای خوانا.
- دسترس‌پذیری: لینک پرش، `aria-label`، فوکوس قابل مشاهده، کنتراست مناسب.

## تبدیل به Razor Pages

1. فایل‌های CSS/JS/تصاویر/فونت را به `wwwroot/` منتقل کنید.
2. برای هر صفحه یک Razor Page بسازید (مثلاً `Pages/Products.cshtml`) و محتوای بخش `<main>` را داخل `_Layout.cshtml` قرار دهید.
3. هدر و فوتر هر پوسته در `layouts.py` (سمت ابزار تولید) و در خروجی HTML داخل `header.site-header` و `footer.site-footer` قرار دارد؛ همان بلوک‌ها را به `_Layout` منتقل کنید.
4. تصاویر محصولات در پروژه اصلی از مسیر `wwwroot/Pictures/...` (توسط `IFileUploader`) تامین می‌شوند؛ مسیر تصاویر نمونه را با `@Model.Picture` جایگزین کنید.
5. اعتبارسنجی فرم‌ها با `jquery-validation` در پروژه موجود انجام می‌شود؛ کلاس‌های `field`، `error` و پیام‌ها آماده اتصال هستند.

## سفارشی‌سازی رنگ‌ها

در ابتدای فایل CSS متغیرهای زیر قابل تغییرند:

```css
:root{
  --c-brand: ...;   /* رنگ اصلی برند */
  --c-ink:   ...;   /* رنگ متن اصلی */
  --c-soft:  ...;   /* رنگ پس‌زمینه ملایم */
}
```
